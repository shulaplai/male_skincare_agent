SkinCoach · 手機版樣式選擇

揀一個手機版樣式

三個都係同一個手機版 app：同樣五個底部 tab、同樣真數據、同樣元件。分別係主角、 色系同打卡入口。下面係縮細預覽，撳「全屏睇」開獨立頁（可以撳、可以切日夜）。

點睇：撳下面任何一張卡嘅「全屏睇」→ 獨立頁；頁面右下角有列可以即刻跳去另外兩個樣式。
開唔到／iframe 空白：喺 repo root 行 python3 -m http.server 8080 --bind 127.0.0.1 --directory design，再開 http://127.0.0.1:8080/mobile.html。
（唔好就咁 python3 -m http.server 喺 repo root 行 —— 咁會連 backend/.env 都 serve 出去，而且默認 bind 晒所有 interface。上面條 command 只 serve design/、只限本機。直接雙擊開 file:// 一般都冇問題。）
真手機睇：喺個 URL 後面加 #noframe（例如 mobile-1-soft-cards.html#noframe）， 就會去掉機殼同假 status bar、全屏填滿。
要注意：樣板入面所有數字同文字都係假數據（每份都有標示），用嚟比較視覺，唔代表 app 有呢啲內容。
唔關事：呢三個樣式同出貨 app 三個桌面結構（教練對話／皮膚日記／進度儀表板）係兩件事 —— 桌面結構係「排法」，呢度係「手機上嗰個排法長咩樣」。
