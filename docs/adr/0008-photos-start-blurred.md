# 皮膚相一律由模糊開始，要撳「顯示」才清

任何地方顯示皮膚相，都要由模糊狀態開始，冇「我睇過就唔再模糊」嘅記憶（reload 之後亦一樣）。

**Considered options**：直接出清（方便）—— 拒絕，因為皮膚相係自拍，喺公眾地方開 app 就等於行過嘅人一眼睇晒。呢個係 UI 層嘅遮蓋，同 ADR-0001 嘅 consent 係**兩件唔同嘅事**，兩樣都要。

**Consequences**：每個 render 皮膚相嘅地方都要經同一個 component，否則就會漏。**實際漏過**：規則寫落指引之後，仍然有三個頁面係裸 `<img>`，其中一個仲包住 `<a target="_blank">`（撳一下喺新 tab 開原圖，繞過模糊）。當時 51 個 snapshot 全綠 —— 因為測試用嘅假相係低對比漸變，模糊對佢嘅影響低過像素門檻。所以呢條規則係用**斷言**（每張相都要有模糊 wrapper、唔可以喺 anchor 入面）守住，唔係靠 snapshot。
