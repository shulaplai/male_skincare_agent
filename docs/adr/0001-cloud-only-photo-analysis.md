# 相片分析只有雲端一條路，同意只問一次

用戶嘅皮膚相係送去雲端 vision model 分析嘅，呢個 app 冇「本地模式」。原本嘅設計有 per-conversation 嘅本地／雲端開關，但單一用戶自用嘅情境下，個開關只係多一個冇人會撳嘅掣，所以 2026-10-01 移除咗，改成一次性、長期有效嘅同意。

**Considered options**：保留本地模式（唔送相上雲、只做文字分析）—— 拒絕，因為冇本地 vision model，結果係「有相但永遠睇唔到」，比老實講「相會上雲」更差。改成每次問同意 —— 拒絕，因為同一個用戶每日問一次，最後用戶會變成盲撳。

**Consequences**：同意同「相喺螢幕度畀邊個睇到」係**兩件唔同嘅事** —— 前者係呢個 ADR，後者係 ADR-0008。撤回同意要保留「曾經同意」嘅歷史標記，否則重啟會靜靜幫人開返。多人部署要將同意改返做必須問，唔可以照搬單用戶嘅預設。
