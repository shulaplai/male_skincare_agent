# 一條片係一條片：抽格係 backstage，永遠唔會 leak 俾用戶

上載嘅片由 ffmpeg 抽最多 6 格餵入 vision model。UI **永遠唔會**講「抽咗 6 張相」、「格數」、「已壓縮 MB」或者「幾格太似」，對話只出一張中性 chip（「🎬 皮膚影片」）。prompt 亦明文禁止 model 用任何「格」嘅講法。

**Considered options**：向用戶展示抽格結果（原本嘅行為，有一行行縮圖同進度文案）—— 2026-10-01 用戶明確要求刪走。理由係呢啲全部係實作細節，講咗只會令用戶以為自己要理解 ffmpeg 嘅行為，而佢真正要做嘅事只有一件：**鏡頭慢慢掃過成塊面**。

**Consequences**：呢個係一個刻意嘅資訊隱藏，所以**未來讀 code 嘅人一定會覺得奇怪**（明明真係抽咗 6 格，點解 UI 一句都唔講）。另外：抽格會丟音軌（`-an`），所以「講出嚟嘅聲」係真嘅唔會記錄 —— 呢句係產品事實，唔可以為咗好聽而刪。覆蓋範圍取決於**鏡頭有冇移動**：20 秒定鏡只出 1 格，10 秒橫掃出足 6 格，所以提示一定要喺拍之前講。
