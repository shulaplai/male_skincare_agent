# 單一用戶、local-first，唔做多用戶部署

呢個 app 係一個人自己喺自己部機用嘅：SQLite 喺本機、相片喺本機、冇 auth、冇 multi-tenant。呢個係刻意嘅邊界，唔係未做。

**Considered options**：「做唔做多用戶」喺規劃階段曾經被提出作為檢討題目，而**主動冇採用** —— 加多用戶就會引入 auth、租戶隔離、每用戶同意管理同部署維運，全都係為一個唔存在嘅用戶做。反過來，喺呢個邊界之內：「單用戶」令好多安全預設可以簡化（例如同意可以假定已給、唔使問），但唔可以令佢哋變成**唔存在** —— server-side 嘅同意檢查必須留喺度，唔係嘅話 hosted 部署就係一個改 config 就穿嘅窿。

**Consequences**：任何新功能都唔可以假設有第二個用戶或者第二部裝置。雲端同步、分享、協作全部唔喺範圍。想搬去 hosted 之前，最少要處理：同意改返做必須問、backup／restore、同埋所有「本機」假設（例如相片直接由本機路徑讀）。
