# 皮膚保濕與屏障
皮膚屏障主要由角質層同脂質組成，保濕係維持屏障功能嘅關鍵。
神經醯胺、甘油、透明質酸係常見保濕成分。
皮膚乾燥會令屏障受損，增加敏感同泛紅風險。
過度清潔會洗走皮脂，令皮膚更容易乾燥。

# 暗瘡成因與處理
暗瘡主要因為皮脂分泌過多、毛囊角化異常、痤瘡丙酸桿菌增生同發炎。
水楊酸係油溶性，可以疏通毛孔，幫助改善粉刺同閉口。
過度清潔同摩擦會刺激皮膚，令暗瘡惡化。
擠暗瘡容易留印同感染，應該避免。

# 控油
油性皮膚要揀清爽、非致粉刺嘅產品。
控油唔等於完全去除油脂，過度去油反而會刺激皮膚分泌更多油。

# 防曬
每日防曬可以預防色素沉澱、光老化同暗瘡印加深。
廣譜防曬要同時防 UVA 同 UVB，日常用 SPF 30 以上比較理想。
油性肌可以揀清爽、不致粉刺嘅防曬。

# 敏感肌
敏感肌要避免酒精、香料同刺激性成分。
新產品要逐次引入，做局部測試，避免一次過換太多產品。
屏障受損時要精簡步驟，先做好保濕同防曬。

# 成分
水楊酸（BHA）係油溶性，可以深入毛孔去角質。
維他命 B5（泛醇）有助修復屏障同保濕。
維他命 A 醇可以刺激膠原同加速角質更新，但要逐步建立耐受。
維他命 C 可以抗氧化、提亮膚色，日間配合防曬效果更好。
煙醯胺有助控油、淡印同強化屏障。

# 飲食與皮膚
高糖同高升糖指數食物可能加劇暗瘡。
奶製品同暗瘡嘅關聯因人而異，建議做飲食日記觀察。
辣嘢本身未必直接致痘，但可能令已發炎嘅皮膚更紅。

# 護膚步驟
基本護膚流程：清潔、保濕、防曬。
油性肌晚間可以加入水楊酸精華幫助控油去角質。
引入新產品要用單一變數測試，方便搵出致敏源。
